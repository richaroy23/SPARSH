🔍 Problem & Solution

❌ The Problem

In today's world, physical interaction with devices poses multiple challenges:

  • Hygiene Concerns: Touchscreens and keyboards carry harmful bacteria and viruses
  • Accessibility Issues: People with mobility impairments struggle with traditional interfaces
  • Efficiency Gaps: Constant switching between input methods wastes time
  • Hands Busy Scenarios: Inability to control devices while hands are occupied
  • Long-term Fatigue: Extended use of traditional input methods causes strain injuries

✅ Our Solution

SPARSH (Sensing Precise Actions for Responsive and Smart Handling) revolutionizes human-computer interaction through:

  • Gesture Recognition: Control your cursor using hand gestures captured via webcam
  • Voice Commands: Execute actions with natural voice commands
  • Dual-Mode System: Switch seamlessly between gesture and voice control
  • No Contact Required: Completely touchless operation for maximum hygiene
  • Real-time Processing: Instant response using advanced AI and computer vision

⭐ Key Features

👆 Gesture Control

Point, click, and drag using hand gestures detected via webcam with high precision

🎤 Voice Recognition

Type and execute commands using natural speech-to-text technology

⚡ Real-time Response

Instant processing and execution of commands with minimal latency

🌍 Universal Compatibility

Works with any application on your computer without special configuration

📖 How to Use SPARSH

SPARSH offers two powerful ways to control your computer. Choose the module that best fits your needs:

👆 Gesture Control

sparsh_unified.py

Control your mouse cursor and perform clicks using natural hand gestures. Perfect for hands-free interaction while working or presenting.

Quick Start:
  1. Ensure your webcam is connected
  2. Click "Launch Gesture Control" below
  3. Position your hand in front of the camera
  4. Use gestures to control the mouse and click
  5. Press 'Q' to exit the application

🎤 Voice Control

voice.py

Type and control your computer using voice commands. Great for when you need to input text quickly without touching the keyboard.

Quick Start:
  1. Ensure your microphone is connected
  2. Click "Launch Voice Control" below
  3. Say "type" to start voice typing mode
  4. Speak what you want to type
  5. Say "exit" to quit the application

📋 Detailed Usage Guide

Gesture Control Features:

  • Mouse Movement: Move your hand to move the cursor smoothly across the screen
  • Click Action: Form a specific gesture with your fingers to perform a click
  • Drag & Drop: Maintain the click gesture while moving your hand to drag objects
  • Smooth Tracking: Advanced smoothing algorithms ensure fluid cursor movement
  • Sensitivity Settings: Automatically calibrated for optimal response

Voice Control Commands:

  • "type": Activates voice typing mode - place your cursor where you want to type
  • "stop typing": Pauses voice typing mode
  • "exit": Closes the voice control application
  • Speech Recognition: Speaks clearly for best accuracy with Google's speech recognition API
  • Natural Language: Supports multiple languages and accents
💡 Pro Tips:
  • Ensure good lighting for gesture control to work optimally
  • Speak clearly and at a normal pace for voice recognition
  • Use gesture control for precise navigation and voice for text input
  • Close other applications for better system performance
  • Keep your camera and microphone clean for best results

What is SPARSH?

SPARSH is an innovative touchless control system developed in NIRMAAN. It represents the next generation of human-computer interaction, combining cutting-edge computer vision and machine learning technologies with practical everyday applications.

Our Vision

We envision a world where technology is accessible to everyone, regardless of physical ability or circumstances. SPARSH breaks down barriers by providing a universal interface that works through natural human gestures and voice.

Technology Stack

  • Computer Vision: Python with OpenCV for real-time video processing, MediaPipe for hand-landmark detection, NumPy for calculations, PyAutoGUI for OS-level mouse/keyboard control, and a webcam for vision input.
  • Speech Recognition: SpeechRecognition (Google Speech-to-Text API) for voice input, PyAudio for microphone capture, and PyAutoGUI for OS-level keyboard automation.
  • Real-time Processing: Optimized algorithms for instant response

Use Cases

  • 🏥 Healthcare: Controlling medical devices without contamination
  • 🎓 Education: Interactive presentations and remote learning
  • ♿ Accessibility: Assistive technology for people with disabilities
  • 🎮 Entertainment: Immersive gaming and VR interactions
  • 🏭 Industrial: Touchless control in manufacturing environments
  • 📚 Productivity: Hands-free work while multitasking

System Requirements

  • Windows/Linux/Mac operating system
  • Webcam (for gesture control)
  • Microphone (for voice control)
  • Python 3.7 or higher
  • Internet connection (for speech recognition)
